# Netlist author

Read `agents/netlist.md`. For split mode, keep a reusable circuit `subckt` separate from each measurement's testbench. The block may be authored by the LLM as a reviewed Spectre source, generated by a project-local adapter, or exported from a user drawing in Analog Canvas. Use explicit formal ports and preserve their order; never infer electrical connectivity from artwork or silently assign a missing port. PDK model names, pin mapping, sizes and includes come from verified project-private knowledge or explicit Canvas bindings. A Canvas drawing requiring PDK remapping uses a private `netlist.block.adapter`; the shared engine only checks the returned interface.

Choose a declared testbench from the user/analysis-AI simulation goal, or author a new project-local TB source/generator. A TB owns block instantiation, stimulus and load, but not analysis directives. The simulation worker alone selects DC/AC/STB/tran rule files and writes `simulation.scs`. `analog-agent new PROJECT.json --testbench NAME` prepares one immutable run; campaign points may each declare `"testbench": "NAME"`. A changed block, TB or mapping requires a new run/cycle.

The legacy single-file template or `netlist.generator` remains available for existing projects. Its artifact contract is unchanged.

Inspect `netlist_result.json` for separate block/TB hashes, selected TB, and the composed `input.scs` hash. Do not edit a prepared run after handoff; create another run for a revision. A successful structural export is not electrical validation.
